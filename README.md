<h1 align="center">🧮 Calculator in 30 Lines with GUI</h1>

<p align="center">
  A beautiful calculator built with <code>Python</code> and <code>ttkbootstrap</code> in just ~30 lines of code. Supports all basic arithmetic operations using <code>eval()</code> and dynamically generated buttons using <code>exec()</code>.
</p>

<p align="center">
  <img src="https://img.shields.io/badge/python-3.9%2B-blue" />
  <img src="https://img.shields.io/badge/ttkbootstrap-%20GUI%20Toolkit-green" />
</p>

<hr>

<h2>✨ Features</h2>
<ul>
  <li>✅ Lightweight and clean GUI with <code>ttkbootstrap</code> themes</li>
  <li>✅ Basic operations: +, -, *, /, %, ()</li>
  <li>✅ Decimal point support</li>
  <li>✅ Backspace and clear functionality</li>
  <li>✅ Innovative use of <code>eval()</code> for calculations</li>
  <li>✅ Dynamic button creation using <code>exec()</code></li>
</ul>

<h2>🧠 Logic Explanation</h2>
<ul>
  <li><b>eval():</b> Used to convert string expressions like "2+3*(4-1)" into real math and evaluate them.</li>
  <li><b>exec():</b> Dynamically creates buttons in a loop without repeating code, improving compactness.</li>
  <li><b>Entry Widget:</b> Acts as the display screen of the calculator.</li>
</ul>

<h2>📁 Code Files</h2>
<p>There are two versions:</p>
<ul>
  <li><b>With exec():</b> Compact, dynamic, under 30 lines.</li>
  <li><b>Without exec():</b> More explicit, each button manually defined.</li>
</ul>
